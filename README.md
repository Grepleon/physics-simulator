# Как изменяется положение тела? — полунеявный метод Эйлера
Процесс вычисления изменения координат для следующего момента времени можно вычислить зная вектор его ускорения и скорость в данный момент времени
> V = v + a * Δt, где V - новая скорость тела, v - старая скорость тела, a - ускорение тела, Δt - единица времени

Ускорение же тела можно вычислить, зная вектор действующей на тело силы и массу тела,
> a = F / m, где a - ускорение тела, F - сила, действующая на тело, m - масса тела

Предварительно вычислив новую скорость тела, изменяем координаты тело на скорость, умножив на единицу времени
> x = x0 + V * Δt, где Δt - единица времени, V - проекция скорости тела на ось x, x0 - начальная координаты, x - конечная координата
